# Additional Things Guide

Консольное приложение-справочник по моду **Additional Things**.

## Возможности

- Информация о рудах.
- Информация о еде.
- Информация о броне и инструментах.
- Информация о моде.

## Лицензия

GPL v2.

## Ссылка на мод

https://minecraft-inside.ru/abyss/189188-additional-things.html

## Сборка

1. Скачайте папку `src/` и файл `build.bat`;
2. Поместите их в 1 папку;
3. Запустите `build.bat`, а после удачной сборки закройте консоль.
